# Travel Planner 🌍

A full-stack web application for planning and managing trips, built with Flask and SQLite.

## Features

* 👤 **User Accounts** — Register and log in with secure password hashing
* ✈️ **Trip Management** — Create, edit, and delete trips with start/end dates
* 💰 **Budget Tracking** — Set a trip budget, track spending, and monitor remaining funds
* 💸 **Expense Tracking** — Add, edit, and delete expenses by category, with spending summaries
* 📌 **Saved Places** — Save places to visit, optionally associate them with a trip, and mark them as visited
* 📋 **Trip Checklists** — Create, edit, delete, and mark checklist items as completed
* 📊 **Trip Overview** — View budget usage, total spending, remaining budget, and daily spending allowance

## Technologies

* **Backend:** Python, Flask
* **Database:** SQLite
* **Frontend:** HTML, CSS, Bootstrap
* **Templating:** Jinja2
* **Version Control:** Git, GitHub
