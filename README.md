# Travel Planner 🌍

CS50 Final Project

## Description

Travel Planner is a web application that helps users organize and manage their trips.

Users will be able to:
- Create and manage trips
- Plan itineraries
- Track budgets
- Create packing lists

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
